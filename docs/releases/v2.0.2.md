Smoother scrolling in the code editor and the terminal.

- **No more flicker while scrolling code.** A fast scroll could outrun Neovim: the text stopped for a frame, then jumped ahead when Neovim caught up. Neovim now keeps more lines ready beyond the edge of the editor, ahead in the direction you scroll, and re-centers them when you stop, so changing direction doesn't wait either.
- **Even motion in the terminal and the editor.** When trackpad reports arrived slightly early, two of them could be drawn in one frame and almost nothing in the next. Each report now continues the previous one's motion instead. Slow scrolling keeps the same responsiveness.

Measured from recorded frames scrolling through a real file (uneven steps per screen refresh): terminal 17 of 69 → 2 of 80, editor 39 of 132 → 8 of 140.

**Install or update**

macOS (Apple silicon, macOS 13+): quit NeoLink, then run

```bash
curl -fsSL https://raw.githubusercontent.com/abhayasho/NeoLink/main/scripts/install.sh | bash
```

or download **NeoLink-macos-arm64.zip** and drag the app to Applications. Windows (x64): download **NeoLink-windows-x64.zip**, extract the folder and run `NeoLink.exe`.

The app is ad-hoc signed and not notarized; macOS may ask you to allow the first launch ([Apple's instructions](https://support.apple.com/en-us/102445)), and Windows SmartScreen may ask too.
