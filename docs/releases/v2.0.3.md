A polish release.

- **Agent conversations read in order.** Tool calls now appear where they happened in a reply, instead of all after the reply's text, and the agent's name is shown once per reply.
- **Agent launcher:** choosing Custom CLI selects the prefilled name, so typing replaces it instead of adding to it.
- **Dialogs** dim the window evenly again (2.0.0 had doubled the dimming behind some of them).
- **Tab strip:** when tabs are hidden past an edge, that edge fades, so you can tell the strip scrolls.
- **New file or folder:** the destination is shown as `~/…`, like the rest of the app.

**Install or update**

macOS (Apple silicon, macOS 13+): quit NeoLink, then run

```bash
curl -fsSL https://raw.githubusercontent.com/abhayasho/NeoLink/main/scripts/install.sh | bash
```

or download **NeoLink-macos-arm64.zip** and drag the app to Applications. Windows (x64): download **NeoLink-windows-x64.zip**, extract the folder and run `NeoLink.exe`.

The app is ad-hoc signed and not notarized; macOS may ask you to allow the first launch ([Apple's instructions](https://support.apple.com/en-us/102445)), and Windows SmartScreen may ask too.
