A polish release.

- **Source Control** shows diffs the way you expect: starting at the first change, with added and removed lines tinted across the width. Changed files show their icon, name and folder, and status letters in color (U for new files).
- **Quick Open and Find in Files** show each file's icon with its name first and folder dimmed; Find in Files highlights the match in every line it lists.
- **Editor:** the fold column beside the line numbers marks only folds you have closed, instead of a column of nesting digits and bars (Neovim 0.12; on 0.11 the digits remain).
- **Notices:** information is shown in neutral gray and problems in red with a warning mark; every notice has a close button.
- **Performance Monitor** text wraps inside its panel; an unsaved tab shows a round dot; the empty connections list has an Add connection button.

**Install or update**

macOS (Apple silicon, macOS 13+): quit NeoLink, then run

```bash
curl -fsSL https://raw.githubusercontent.com/abhayasho/NeoLink/main/scripts/install.sh | bash
```

or download **NeoLink-macos-arm64.zip** and drag the app to Applications. Windows (x64): download **NeoLink-windows-x64.zip**, extract the folder and run `NeoLink.exe`.

The app is ad-hoc signed and not notarized; macOS may ask you to allow the first launch ([Apple's instructions](https://support.apple.com/en-us/102445)), and Windows SmartScreen may ask too.
