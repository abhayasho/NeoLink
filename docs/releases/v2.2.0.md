NeoLink now runs on **Intel Macs** too, and gains a command palette, reopened files and an update check.

- **Command palette.** Press ⇧⌘P or F1 (Ctrl+Shift+Alt+P on Windows) to find any command by typing a few of its letters; each shows its shortcut, and the ones you used recently come first. On Windows, which has no menu bar, it reaches every command.
- **Your files reopen.** NeoLink reopens the files that were open when you quit and shows the same tab.
- **Check for Updates** in the Help menu (and the palette) asks GitHub for the latest release only when you choose it, and offers to open its page. NeoLink still makes no network connections on its own.
- **Intel Macs.** The macOS download is now one universal app for Apple silicon and Intel, and the install command works on both.

**Install or update**

macOS (macOS 13+, Apple silicon or Intel): quit NeoLink, then run

```bash
curl -fsSL https://raw.githubusercontent.com/abhayasho/NeoLink/main/scripts/install.sh | bash
```

or download **NeoLink-macos-universal.zip** and drag the app to Applications. Windows (x64): download **NeoLink-windows-x64.zip**, extract the folder and run `NeoLink.exe`.

`NeoLink-macos-arm64.zip` is the same universal app under its old name, for existing links.

The app is ad-hoc signed and not notarized; macOS may ask you to allow the first launch ([Apple's instructions](https://support.apple.com/en-us/102445)), and Windows SmartScreen may ask too. The Intel version has been tested under Rosetta on Apple silicon; reports from Intel Macs are welcome.
