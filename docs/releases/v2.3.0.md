Smoother scrolling, no more flicker, and input methods.

- **Smoother scrolling in the terminal and the editor.** A trackpad reports on its own clock, so its reports used to arrive two in one frame and none in the next, and the text moved in uneven jumps. Each report now gets its own frame. In measured runs the worst stutter in the editor fell from 24 pixels to 2, and in fast flicks from up to 59 pixels to under 4, for about 4 ms of extra delay.
- **No more dimming flicker while scrolling.** MacBook Pro displays (ProMotion) follow an app's frame rate, and NeoLink sent frames unevenly during a scroll, so the display kept changing its refresh rate and dark backgrounds pulsed in brightness. NeoLink now keeps a steady frame rate for the whole scroll; an idle window still uses no CPU.
- **Input methods.** Chinese, Japanese, Korean and other input methods, and dead keys (such as Option-E then E for é), work in the terminal, the editor and the built-in editor: the text being composed is shown underlined at the cursor, with the candidate window beside it.

**Install or update**

macOS (macOS 13+, Apple silicon or Intel): quit NeoLink, then run

```bash
curl -fsSL https://raw.githubusercontent.com/abhayasho/NeoLink/main/scripts/install.sh | bash
```

or download **NeoLink-macos-universal.zip** and drag the app to Applications. Windows (x64): download **NeoLink-windows-x64.zip**, extract the folder and run `NeoLink.exe`.

The app is ad-hoc signed and not notarized; macOS may ask you to allow the first launch ([Apple's instructions](https://support.apple.com/en-us/102445)), and Windows SmartScreen may ask too.
