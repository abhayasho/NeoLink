A visual polish release.

- **Tabs** belong to the page: the shown tab takes the editor's color and flows into it, on a darker strip.
- **Editor toolbar** shows where the file is in the project (`crates › core › src › scroll.rs · Rust`), shortening from the left in narrow windows.
- **Neovim's mode** is a small colored pill in the editor footer: blue for Insert, neutral for Normal, violet for Visual and Command.
- **Scroll indicator:** a slim thumb at the right of the editor and terminal while you scroll, fading out after.
- **Explorer** has faint indent guides tying nested files to their folders.
- **Quick Open** highlights the letters you typed in each file name.
- **Quieter details:** Neovim's status line sits on the editor's background under a hairline; every dialog's main button uses the same blue; a running shell shows a round green light.

**Install or update**

macOS (Apple silicon, macOS 13+): quit NeoLink, then run

```bash
curl -fsSL https://raw.githubusercontent.com/abhayasho/NeoLink/main/scripts/install.sh | bash
```

or download **NeoLink-macos-arm64.zip** and drag the app to Applications. Windows (x64): download **NeoLink-windows-x64.zip**, extract the folder and run `NeoLink.exe`.

The app is ad-hoc signed and not notarized; macOS may ask you to allow the first launch ([Apple's instructions](https://support.apple.com/en-us/102445)), and Windows SmartScreen may ask too.
